# Inertia Islands Examples

This directory contains example implementations of Inertia Islands for different frameworks.

## Available Examples

### React
- **[react-island-example.tsx](./react-island-example.tsx)** - Complete React example showing:
  - Static header and footer components
  - Dynamic Inertia island for main content
  - Loading states and customization options
  - Example page component structure
  - Laravel backend setup

## Running the Examples

These are example files meant to demonstrate the API and usage patterns. To actually run an island-based app:

1. Set up a Laravel backend with Inertia
2. Create a frontend using React, Vue, or Svelte
3. Use the `InertiaIsland` component from `@inertiajs/react`, `@inertiajs/vue3`, or `@inertiajs/svelte`
4. Follow the patterns shown in these example files
